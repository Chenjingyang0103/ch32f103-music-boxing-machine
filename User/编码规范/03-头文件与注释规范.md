# 3. 头文件与注释规范

> 头文件只放声明与类型；注释以 Doxygen 风格为主，全中文。

## 3.1 头文件规范

1. 头文件内容顺序：保护宏 → `#include` → 宏/常量 → 枚举 → 结构体 → 对外函数声明。
2. 头文件只放声明与类型，不放实现；私有结构体可保留在 `.h` 中但需注明“外部不可见”。
3. 对外接口函数在声明行尾用 `//` 简述用途、参数与返回值：

```c
void Punch_Init(AdcDevNumTypedef DevNum);                        // 初始化击打检测状态与阈值
uint8_t Punch_IsHit(AdcDevNumTypedef DevNum);                    // 是否检测到击中（边沿触发，击中一次返回1后自动清零）
float Punch_GetPeakForce(AdcDevNumTypedef DevNum);               // 获取本次击打的峰值力度（单位：g）
void Punch_ClearPeakForce(AdcDevNumTypedef DevNum);              // 清空峰值力度（准备新一轮击打）
```

4. 未启用的接口保留但注释，并说明原因，不直接删除：

```c
/* 下部分为低功耗代码, 本项目中未使用因此注释掉了, 如果需要使用可以解除注释 */
// void HCT6521_LowPower(AdcDevNumTypedef DevNum, FunctionalState Enable);
```

## 3.2 模块文件头

较大的模块在 `.c` 顶部使用横幅式文件头：

```c
/**
 *********************************************************************************
 * @file    Calibration.c
 * @brief   标定模块：持有标定表，提供稳定判定、标定点设置、查询接口
 * @note    - 标定表 s_cal[ADC_DEV_NUM][ADC_CAL_POINTS]：0=零点，1~5=砝码点
 *          - 倍率表 s_rate[ADC_DEV_NUM]：单点标定得出的整体增益
 *          - 与 MyFlash 同步：Cal_Load / Cal_Save
 *********************************************************************************
 */
```

## 3.3 函数注释（Doxygen 风格）

模块级函数统一使用 Doxygen 注释，中文说明，标签用 `@brief` / `@param` / `@retval` / `@note` / `@warning`：

```c
/**
 * @brief  状态机主函数，每周期调用一次
 * @param  DevNum  通道号
 * @param  force  当前重量（g）
 * @retval None
 * @note   三态流转：Idle → Confirm → Track → Idle
 */
void Punch_Tick(AdcDevNumTypedef DevNum, float force)
```

- `@brief` 必填；有参数用 `@param`；有返回值用 `@retval`（不使用 `@return`）；重要前提用 `@warning`。
- 阻塞 / 耗时的函数必须写明 `@note 会阻塞主循环`。

## 3.4 行内与分区注释

- 分区横幅：主分区用 `/* ==================== 标题 ==================== */`，
  子分区用 `/* ---- 标题 ---- */`，步骤用 `/* ---- 1. 步骤 ---- */`。
- 关键语句行尾补中文短注释，长表格逐行对齐：

```c
/* ==================== 默认标定表 ==================== */
/* 行索引 = AdcDevNumTypedef，列索引 = CalPointTypedef */
static const int32_t s_defaultCal[ADC_DEV_NUM][ADC_CAL_POINTS] = {
    /* 空载    200g    500g    1000g   2000g   4000g */
    {2681, 4538, 7328, 11966, 21251, 39821},   // AdcDevNum0
    {3646, 3784, 4045, 4394, 4849, 5759},      // AdcDevNum1
    {0, 0, 0, 0, 0, 0},                         // AdcDevNum2（未标定）
};
```

- 对“废弃 / 未使用 / 暂未启用”的代码，用注释保留并标注状态，禁止裸删：

```c
// 已废弃：统一使用 Project_Config.h 中的 AdcDevNumTypedef，本枚举不再使用
// typedef enum { ... } PunchDevNumTypedef;
```
