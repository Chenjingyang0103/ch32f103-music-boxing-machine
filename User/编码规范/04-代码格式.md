# 4. 代码格式

> 缩进、括号、空格与分支写法的统一约定。

## 4.1 缩进与括号

- 缩进：**4 个空格**，不使用 Tab（重排版后的模块以 4 空格为准）。
- 括号：函数体与控制块采用 Allman 风格（左花括号独占一行）：

```c
void Punch_Reset(AdcDevNumTypedef DevNum)
{
    PunchRunningParamTypedef *pRun = &PunchDeviceParam[DevNum].RunningParam;
    pRun->state = PunchState_Idle;
}
```

## 4.2 空格

- `if` / `for` / `while` / `switch` 后加一个空格，运算符与比较符两侧加空格：

```c
for (uint8_t i = 0; i < ADC_DEV_NUM; i++)
{
    if (force > pSta->TriggerThreshold)
    {
        ...
    }
}
```

## 4.3 switch 写法

- `switch` 的每个 `case` 用花括号包裹，并按状态机语义加注释：

```c
switch (pRun->state)
{
    case PunchState_Idle:
    {
        ...
        break;
    }
    case PunchState_Track:
    {
        ...
        break;
    }
    /* 异常状态，强制回 IDLE */
    default:
    {
        pRun->state = PunchState_Idle;
        break;
    }
}
```

## 4.4 历史差异

早期文件如 `main.c`、`HCT6521.c`、`HCT6521.h`、`SM16028E.h`、`GameLogic.h`、`PunchDetect.h`
曾存在 Tab 与 2 空格缩进残留，已于全量复审中统一为 4 空格；新增与改动代码一律按本章格式对齐。
