# 2. 命名规范

> 一律使用英文标识符 + 中文注释，命名需能从名字看出所属模块与用途。

## 2.1 文件与宏

- 头文件保护宏：`__模块名_H`，全大写，前后双下划线。

```c
#ifndef __PUNCHDETECT_H
#define __PUNCHDETECT_H
...
#endif
```

- 宏定义全大写 + 下划线分隔，统一集中在 `Project_Config.h`：

```c
#define ADC_DEV_NUM                 6       // 设备数量
#define TRIGGER_THRESHOLD           100     // 开始追踪的门槛（重量 g）
#define GAME_TICK_PERIOD_MS         150     // 游戏逻辑计数周期，单位毫秒
#define MAX_ROUNDS                  10000   // 总回合数,值不能大于65535
```

- 底层电平操作宏以“功能名(参数)”形式定义，便于替换实现：

```c
#define SDO(emDevNum)        SdoReadLevel(emDevNum)
#define SCLK_L(emDevNum)     SckSetLow(emDevNum)
#define SCLK_H(emDevNum)     SckSetHigh(emDevNum)
```

## 2.2 类型与枚举

- 类型名使用 `大驼峰 + Typedef` 后缀：

```c
typedef enum { ... } AdcDevNumTypedef;
typedef enum { ... } GameStateTypedef;
typedef enum { ... } CalPointTypedef;
typedef struct { ... } WeightInfoTypedef;
typedef struct { ... } MyFlashParamTypedef;
```

- 枚举成员使用 `枚举主题_取值`，并**显式赋初值**、逐行对齐注释：

```c
typedef enum
{
    PunchState_Idle = 0,    // 空闲，等待冲击开始
    PunchState_Confirm,     // 已有一个点超触发阈值，等第二个点确认
    PunchState_Track,       // 已确认真实冲击，持续追踪峰值
} PunchStateTypedef;

typedef enum
{
    AdcGain_128           = 0x00,     // 128 倍
    AdcGain_64            = 0x01,     // 64 倍
    AdcGain_1             = 0x03,     // 1 倍
} AdcGainTypedef;
```

## 2.3 函数

- 函数名采用 `模块前缀_动作` 的“大驼峰”形式：

```text
HCT6521_Init / HCT6521_Task / HCT6521_Config
Filter_Init / Filter_AdcFilt
Weight_Init / Weight_Update / Weight_GetValue
Cal_Init / Cal_SetZero / Cal_WaitStable / Cal_GetRate
Punch_Init / Punch_Tick / Punch_IsHit / Punch_GetPeakForce
Game_Init / Game_Start / Game_Task / Game_GetState
SM28_Init / SM28_ShowMaxForce / SM28_Update
MyFlash_Init / MyFlash_Save / MyFlash_SetCal / MyFlash_GetRate
MyRTC_Init / Timer2_Init / Key_Init
```

- 动词前缀约定：

| 前缀 | 含义 |
| --- | --- |
| `Init` | 初始化 |
| `Task` | 主循环轮询任务 |
| `Tick` | 周期更新 |
| `Get` / `Set` | 读 / 写 |
| `Is` | 返回布尔判断 |
| `Update` | 刷新状态 |
| `Save` / `Load` | 持久化写出 / 读入 |

## 2.4 变量

- 局部 / 成员变量使用小驼峰，含义明确，不使用歧义缩写：

```c
int32_t  AdRawValue;      // 滤波后AD值
int32_t  FilterValue;
float    PeakForce;       // 本次冲击到目前为止的峰值（g）
uint16_t TotalRounds;     // 当前回合数
```

- 文件级 `static` 状态变量统一加 `s_` 前缀（新代码为准）：

```c
static int32_t s_cal[ADC_DEV_NUM][ADC_CAL_POINTS];
static float   s_rate[ADC_DEV_NUM];
static uint8_t s_valid[ADC_DEV_NUM];
static CalFilterInfoTypedef s_calFilter[ADC_DEV_NUM];
static volatile uint8_t s_KeyPressed = 0;
```

**`s_` 前缀的适用范围（分类说明）**：

1. **状态变量**（计数 / 标志 / 索引等）→ 加 `s_`，如 `s_GameTick`、`s_KeyPressed`；
2. **设备参数数组** → 命名 `XxxDeviceParam[]`，**不加** `s_`
   （如 `AdcDeviceParam` / `PunchDeviceParam` / `SM28DeviceParam` / `WeightInfo` / `FilterInfo`）；
3. **其它模块私有数据缓冲**（如 Flash 的 `buf` / `view`）→ 保持原名，不加 `s_`。

- 模块私有参数数组统一命名 `XxxDeviceParam[]`：

```c
static AdcDeviceParamTypedef   AdcDeviceParam[ADC_DEV_NUM];
static PunchDeviceParamTypedef PunchDeviceParam[ADC_DEV_NUM];
static SM28DeviceParamTypedef  SM28DeviceParam[SM28_DEV_NUM];
```

- 结构体指针沿用 `pRun` / `pSta` 约定：

```c
PunchRunningParamTypedef *pRun = &PunchDeviceParam[DevNum].RunningParam;
PunchStaticParamTypedef  *pSta = &PunchDeviceParam[DevNum].StaticParam;
```

- 中断与主循环共享的变量必须 `volatile`：

```c
static volatile uint32_t s_GameTickMs = 0;   // 累计毫秒，用于产生节拍
static volatile uint32_t s_GameTick   = 0;   // 游戏节拍计数（每150ms+1）
```
