# 6. 数据结构与接口设计

> 有状态模块的参数结构体拆分方式，以及对外接口的返回 / 出参 / 校验约定。

## 6.1 运行 / 静态 / 设备 三段式

凡是有状态的外设或业务模块，参数结构体拆为三段，命名统一：

| 结构体 | 后缀 | 内容 | 生命周期 |
| --- | --- | --- | --- |
| 运行参数 | `XxxRunningParamTypedef` | 动态状态、计数、当前值 | 运行中频繁更新 |
| 静态参数 | `XxxStaticParamTypedef` | 阈值、引脚、配置 | 初始化后不变 |
| 完整设备参数 | `XxxDeviceParamTypedef` | 上两者组合 | 每通道一份 |

```c
typedef struct
{
    PunchStateTypedef   state;          // 状态机当前状态
    float               PeakForce;      // 本次冲击到目前为止的峰值（g）
    uint8_t             Active;         // 1=冲击中，0=空闲
    uint8_t             HitReported;    // 1=有击中事件待上报（边沿触发）
    uint8_t             ReleaseCnt;     // 释放计数器
} PunchRunningParamTypedef;

typedef struct
{
    float   TriggerThreshold;   // 触发阈值（g）
    float   ReleaseThreshold;   // 释放阈值（g）
    uint8_t ReleaseCntLimit;    // 释放计数阈值 N
} PunchStaticParamTypedef;

typedef struct
{
    PunchRunningParamTypedef    RunningParam;   // 运行参数
    PunchStaticParamTypedef     StaticParam;    // 静态参数
} PunchDeviceParamTypedef;
```

- 结构体成员按宽度对齐，行尾统一中文注释并标注单位。
- 结构体实例数组并列书写时，对齐数据类型与变量名。

## 6.2 接口约定

- 返回状态用 `uint8_t`：**1 = 成功，0 = 失败**；查询类函数返回实际数值。
- 需要多返回值时，通过出参指针返回，并在函数入口做 `NULL` / 越界检查：

```c
uint8_t Cal_SetPoint(AdcDevNumTypedef DevNum, CalPointTypedef Point)
{
    int32_t stable_val;

    if (DevNum >= ADC_DEV_NUM) return 0;
    if (Point >= CalPoint_Num) return 0;
    if (Point == CalPoint_Zero) return Cal_SetZero(DevNum);

    if (!Cal_WaitStable(DevNum, &stable_val))
        return 0;   /* 超时 */

    s_cal[DevNum][Point] = stable_val;
    return 1;
}
```

- 边角保护：除零前先兜底、超时后强制复位状态机、异常分支回默认态：

```c
/* 防单点除零 */
for (int i = 0; i < CALTIMES; i++) {
    if (p->DiffCalValue[i] == 0) {
        p->DiffCalValue[i] = 1;
    }
}
```

- “配置—回显—重试”类接口在失败时有限次重试后再返回：

```c
while ((conf_data != cmd) && (reset_time < 10)) {
    reset_time++;
    SpiWriteComCheck(DevNum, cmd);
    conf_data = SpiReadComCheck(DevNum);
}
```
