# 7. 状态机与中断规范

> 非阻塞任务、事件上报，以及中断服务函数（ISR）的编写约定。

## 7.1 非阻塞状态机

- 采集类驱动实现为非阻塞状态机，主循环每圈调用一次，完成一步返回 1：

```c
/**
 * @brief  HCT6521 非阻塞状态机任务，主循环每圈调用一次
 * @retval 1=本次读取完成，0=尚未完成
 */
uint8_t HCT6521_Task(AdcDevNumTypedef DevNum, int32_t *OutValue)
{
    switch (pFsm->AdcFsmState)
    {
        case AdcFsmState_Idle:      { ... }
        case AdcFsmState_Reading:   { ... }
        case AdcFsmState_WaitHigh:  { ... }
    }
    return 0;   // 未完成
}
```

- 状态机状态用枚举 `XxxState_名字`，`default` 分支强制回安全态。
- 业务状态机（如 `Game_Task`）在同一 `switch` 内按状态分派，`case` 块内标明状态流转去向。

## 7.2 事件上报

- 事件上报采用“边沿触发 + 读取即清零”，避免重复触发：

```c
uint8_t Punch_IsHit(AdcDevNumTypedef DevNum)
{
    PunchRunningParamTypedef *pRun = &PunchDeviceParam[DevNum].RunningParam;
    if (pRun->HitReported)
    {
        pRun->HitReported = 0;   // 清除上报标志，防止重复触发
        return 1;
    }
    return 0;
}
```

## 7.3 中断服务函数

- ISR 短小：只置标志 / 计数，重活交给主循环。
- 共享变量 `volatile`；退出前清除中断挂起标志。
- 中断与主循环之间通过 `Get` / `Clear` 接口访问节拍量：

```c
void TIM2_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM2, TIM_IT_Update) != RESET)
    {
        TIM_ClearITPendingBit(TIM2, TIM_IT_Update);
        TempTickMs++;
        GameTickMs++;
        if (GameTickMs >= GAME_TICK_PERIOD_MS)
        {
            GameTick++;
            GameTickMs = 0;
        }
    }
}
```

- CH32F103 无需 `__attribute__((interrupt("WCH-Interrupt-fast")))`；
  若保留该行需按项目现有做法注释并标注“CH32V系列才需要”。
